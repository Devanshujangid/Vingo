# 🍴 VINGO – Food Delivery Web Application

A full-stack **Food Delivery Platform** built using the **MERN stack**, inspired by apps like **Zomato/Swiggy**. It enables users to browse restaurants, place food orders, make secure payments, and track deliveries in **real-time** with live location updates.

---

## 🚀 Features

- 👤 **Role-Based Interfaces**
  - Separate dashboards for **Users**, **Restaurant Owners**, and **Delivery Agents**
  - Owners can manage menus and restaurants
  - Agents can view assigned deliveries and update live status  

- 🔐 **Authentication & Security**
  - Secure login/signup with **Google OAuth** and **JWT-based authentication**
  - OTP-based password reset for account recovery  

- 💳 **Payments**
  - Integrated **Razorpay** for secure online transactions
  - Smooth checkout flow with high transaction success rate  

- 📍 **Real-Time Tracking**
  - **Google Maps API** integrated for delivery location tracking
  - **Socket.IO** for real-time communication between users, delivery agents, and restaurants  

- 🖼️ **Image Management**
  - **Cloudinary** + **Multer** integration for uploading and managing restaurant/food images  

- ⚡ **Frontend Experience**
  - Developed with **React.js** and styled using **Tailwind CSS**
  - State management with **Redux Toolkit** for optimized API calls
  - Responsive, modern, and mobile-friendly design  

---

## 🏗️ Tech Stack

**Frontend:** React.js, Redux Toolkit, Tailwind CSS, Framer Motion  
**Backend:** Node.js, Express.js, REST APIs, Socket.IO, WebRTC  
**Database:** MongoDB with Mongoose ODM  
**Authentication:** Google OAuth, JWT, OTP verification  
**Payments:** Razorpay API  
**Other Tools:** Cloudinary, Multer, Postman, Git, Netlify
